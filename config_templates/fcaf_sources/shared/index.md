# Shared test cases

Shared test cases are not atomic test cases. A test case invokes a complete family of them in one scenario step, for example "Perform all Shared_JSON test cases on the decrypted Authorization Response", and their results form the result of that step. See [Test Case ID](../../index.md#shared-test-cases) for the convention.
