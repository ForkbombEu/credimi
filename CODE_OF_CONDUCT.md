# Code of Conduct

Credimi welcomes 🤗 all who come in peace to support this project.

We don't have a code of conduct or manifesto to adhere to — this is on purpose.

> Be excellent to each other.

If chaos erupts, we'll facilitate our way to a more harmonious and productive
environment.

We accept everyone's contributions without discrimination.
