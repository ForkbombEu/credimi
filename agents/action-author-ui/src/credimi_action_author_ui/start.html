Select a device of an admin-managed Credimi runner and an existing wallet version. Credimi checks your organization ownership, reserves the device and installs the wallet before the chat opens. Use a user key from your Credimi dashboard, not an internal admin or model-provider key.

Devices of admin-managed runners of your organizations; offline devices and devices of runners without a running action author cannot be selected.

Only versions with an installer for the selected device's platform are listed. Slot: onboarding.

Your key is used only in this page's memory and is cleared after the lookup; the session token is cleared when the chat opens. Neither is stored, added to the URL, or sent to the Temporal workflow.
