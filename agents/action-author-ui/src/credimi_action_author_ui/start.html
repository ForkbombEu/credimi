Runner wallet tooling

Start an authoring session:

Select a device of an admin-managed Credimi runner and an existing wallet version. Credimi checks your organization ownership, reserves the device and installs the wallet before the chat opens. This page then follows the device's organization, so Existing sessions lists that organization's sessions.

Use a user key from your Credimi dashboard, not an internal admin or model-provider key.

Devices of admin-managed runners of your organizations; offline devices and devices of runners without a running action author cannot be selected.

Only versions with an installer for the selected device's platform are listed.

Prerequisites

Saved actions of this wallet that build the start state, in order, before exploration and before every replay.

Parameters of the new action

Each parameter gets a fresh value for every exploration and every replay; the action reads it as ${name}. Values are stored in Temporal history: use test data only. HTTP request headers may only be Content-Type, Accept and Accept-Language: never put credentials in a source.

Your key is used only in this page's memory and is cleared after the lookup. The session token is kept in this browser tab's session storage, so the chat can send your save reviews to Credimi; it is never added to the URL or sent to the Temporal workflow.
