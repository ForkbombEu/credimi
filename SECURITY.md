# Security Policy

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities.

Report them privately to <info@forkbomb.eu>. Please include:

- the affected component or version,
- a description of the vulnerability,
- steps to reproduce, and
- any workarounds you have found.

We will acknowledge your report within 5 working days and aim to publish a fix
and advisory as quickly as possible. We credit reporters who follow responsible
disclosure, unless you ask us not to.

## Supported versions

We support the latest release and the current `main` branch. Older releases
receive security fixes only where commercially supported by Forkbomb BV.

## Disclosure

Security fixes are released through the normal release channels with an
advisory. Public disclosure is coordinated with the reporter.
